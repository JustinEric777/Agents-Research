# 附录 D：验证实验矩阵

源码分析之后必须用统一输入验证可观察行为。每次实验都要保存：Agent 版本、运行平台、配置摘要、输入、关键输出、耗时、失败原因和证据等级。

## 场景清单

| 编号 | 场景 | 主要层 | 核心指标 | 通过条件 |
|---|---|---|---|---|
| S01 | 空会话首轮 | L1–L3 | 启动耗时、首 token、首事件 | 能完成首轮且状态可查询 |
| S02 | 连续工具调用 | L3–L5 | 调用顺序、结果回灌、总耗时 | 每个调用都有对应结算 |
| S03 | 并发工具调用 | L4 | 并发度、模型顺序、写回顺序 | 并发不破坏重放顺序 |
| S04 | 工具取消 | L4、L10 | 取消延迟、子进程回收 | 无孤儿进程、结果明确失败 |
| S05 | 动态工具变化 | L5、L12、L13 | schema 更新延迟、可见集合 | 模型只看到有效能力 |
| S06 | 上下文压缩 | L6 | 触发点、压缩耗时、token 变化 | 压缩后关键事实仍可用 |
| S07 | 崩溃恢复 | L7、L8 | 恢复耗时、重复副作用 | 不静默丢失未结算状态 |
| S08 | 子 Agent 委派 | L9 | 上下文、权限、预算、join | 输出归属正确且可回收 |
| S09 | MCP 工具发现 | L5、L13 | 握手、发现、命名、审批 | 能力进入统一权限链 |
| S10 | MCP OAuth 过期 | L10、L13 | 续期行为、错误可见性 | 不泄露 token，不无限重试 |
| S11 | 长时作业重启 | L8、L14 | checkpoint、lease、恢复 | 作业可恢复或明确终止 |
| S12 | 多客户端重连 | L15 | 游标、重复事件、并发写入 | 连接恢复后不重复副作用 |
| S13 | 未知协议字段 | L15 | 忽略、拒绝或降级行为 | 策略可观察且与文档一致 |
| S14 | 遥测关闭 | L17 | 出网请求、日志、功能退化 | 关闭后不发送非必要数据 |
| S15 | 诊断包脱敏 | L10、L17 | secret、URL、prompt 清洗 | 敏感字段不出现在产物中 |

## 统一记录格式

```yaml
scenario: S07
agent: codex
ref: rust-v0.163.0-alpha.11
platform: macos-arm64
config: <redacted summary>
input: <fixture id>
observations:
  - <timestamped event or output>
metrics:
  duration_ms: 0
  first_token_ms: 0
evidence: probe
result: pass|fail|unverified
notes: <scope and limitations>
```

实验未通过时要保留原始输出和最小复现输入；`unverified` 不能被汇总为 `pass`。
