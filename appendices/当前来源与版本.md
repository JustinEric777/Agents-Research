## 这次基线是怎么定的

四个项目「最新」的可达性并不一致，因此取法也不同。下表是本轮的判定依据，避免把「没有新标签」误读成「没有新代码」。

| 项目 | 取法 | 判定依据 |
|---|---|---|
| pi | 取最新标签 | `v1.4.0` 是正式发布标签，可精确锚定；相对旧基线 `v1.2.0` 累计 144 个提交 |
| dsh | 取主干末端 | 末次标签仍是 `dsh-v0.2.1-alpha.3`，但 `master` 已在其后推进 16 个提交 |
| codex | 取主干末端 | 末次标签仍是 `rust-v0.163.0-alpha.13`，但 `main` 已在其后推进 40 个提交 |
| Claude Code | 取 npm 发行物 | 官方只发布平台二进制包，无公开源码标签；本地还原树不作为同版本证据 |

> 主干末端是移动目标。报告中的每条源码断言都绑定到上表的固定提交，而不是「master 上的某一个位置」。
